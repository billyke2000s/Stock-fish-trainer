# Stockfish Trainer

An offline Android chess coach. Start a generated game, choose a move, and practise finding stronger alternatives with Stockfish.

The Android build workflow produces an installable debug APK. The app bundles chess.js 0.10.3 and stockfish.js 10.0.2 at build time. Engine source and build scripts: https://github.com/niklasf/stockfish.js/tree/v10.0.2
